# תוכנית עבודה — הפקת רילס בסגנון Alma

המטרה: ממשפט כמו *"תעשה סרטון על פרויקט X באתונה"* → MP4 מוכן לפרסום, בתהליך קבוע וצפוי.
כל סרטון = תיקייה אחת: `engine/public/projects/<שם>/` עם `video.json` + `captions.json` + `media/` + `audio/`.

---

## שלב 0 — בריף (5 דק')
מה צריך לדעת לפני שמתחילים. אם משהו חסר — שואלים, לא מנחשים מספרים.

- [ ] שם הפרויקט, עיר, שכונה, כתובת / קואורדינטות
- [ ] 3–6 נקודות עניין + זמני הליכה אמיתיים (מטרו, אטרקציות)
- [ ] המספרים: תשואה, תקופה, הון עצמי, אחוז שנמכר, בונוסים (שבוע חופשה, טאבו…)
- [ ] מי מציג (שם לקרדיט), מילת הקוד לתגובות
- [ ] גילוי נאות משפטי (חובה בכל סרטון עם תשואה)
- [ ] חומרים קיימים: צילומים מהשטח, הדמיות, לוגו, קול

## שלב 1 — תסריט (Claude)
כותבים לפי הנוסחה (ראו `01-reverse-engineering.md` §1), 140–160 מילים ≈ 60–70 שניות:

```
Hook אישי עם טוויסט → 3 חושים (לייפסטייל) → מיקום במספרים → המוצר →
מספר גדול + ניטרול התנגדות → "גם אני קניתי" → דחיפות → מחיר כניסה → מילת קוד
```
כללים: משפטים קצרים · מספר אחד לכל משפט · גוף ראשון · בלי מילים "שיווקיות" ריקות · כל משפט = שוט.
תוצר: `script.md` בתיקיית הפרויקט + **רשימת שוטים מוצעת** לכל משפט.

## שלב 2 — קול
שלוש אפשרויות, לפי סדר איכות/אמינות:
1. **אתה מקליט** בטלפון (חדר שקט, 15 ס"מ מהפה, מקריאים את התסריט בקצב מהיר). הכי אמין — זה הסגנון של המקור.
2. **ElevenLabs** עם שיבוט הקול שלך (צריך מפתח API — Claude יבקש אותו דרך טופס מאובטח, לא בצ'אט).
3. קול AI גנרי — רק לטיוטות.

ואז, אוטומטית:
```bash
python3 -I tools/transcribe.py <voice.m4a> engine/public/projects/<p>/captions.json --prompt "שמות מקומות"
```
→ כל מילה עם זמן התחלה/סוף. **זמני התמלול הם שעון-האב של כל העריכה.**

## שלב 4 — עריכה = כתיבת `video.json`
Claude ממפה כל משפט בתמלול לסצנה:
- **סצנות** (`scenes`) — שכבת הוויזואל, רציפות בזמן (`to` של אחת = `from` של הבאה), כל חיתוך **על תחילת מילה**.
- **אוברליים** (`overlays`) — גרפיקה מעל: טבעת, מדבקות, כותרות, גריד, מחיר, CTA, end-card.
- **כתוביות** — אוטומטיות מהתמלול; `highlight` = מילים בזהב; `hide` = טווחים בלי כתוביות (כשיש גרפיקה גדולה); `fixes` = תיקוני תמלול.

כללי עריכה (מהמקור):
1. שוט כל 1.5–2.5 שניות. שוט ארוך = חייב תנועה (זום מפה / פינים / טקסט נכנס).
2. כל מספר שנאמר — מופיע על המסך.
3. גליץ' על "מכות" (מעבר נושא), זום/טשטוש בתוך אותו נושא.
4. תג "הדמיה" על כל ויזואל לא אמיתי.
5. גילוי נאות ב-end card.


## שלב 6 — רינדור וייצוא
```bash
cd engine && node scripts/render.mjs <p>                 # 1080×1920 H.264, AAC
node scripts/render.mjs <p> --from 37 --to 44 --out out/test.mp4   # רק קטע, לבדיקה מהירה
```
אחר כך: נרמול ל-‎-14 LUFS (אם יש מוזיקה+קול נפרדים), ובדיקה בטלפון.

## איך לבקש שינויים (ומה קורה מאחורי הקלעים)

| אתה אומר | Claude משנה |
|----------|-------------|
| "תחליף את התמונה בשנייה 31 בבריכה אחרת" | `scenes[i].src` |
| "המעבר לבניין צריך להיות יותר חלק" | `scenes[i].transition: "blur"` / `transitionDur` |
| "תשנה את התשואה ל-7.5%" | `overlays[statRing].value: 7.5, decimals: 1` + לוודא שגם הקול אומר את זה |
| "הכתוביות גבוהות מדי / גדולות מדי" | `captions.y` / גודל פונט ב-`Captions.tsx` |
| "תצבע את 'בריכה' בזהב" | `captions.highlight` |
| "תוסיף פין של שוק פסירי" | `scenes[map].pins` (+ `satellite_map.py --place` לקואורדינטות) |
| "צבע מותג אחר" | `theme.gold` ב-`video.json` |
| "תקצר ל-45 שניות" | תסריט חדש → הקלטה → תמלול → מיפוי מחדש (המבנה נשמר) |
| "גרסה באנגלית" | פרויקט חדש, `direction` LTR, אותם נכסים |

**כל שינוי = עריכת JSON + רינדור. אין צורך לגעת בקוד, אלא אם רוצים סוג גרפיקה חדש.**
